Introduction

MIST Job Portal is a student project that connects job seekers with employers: register an account, build a profile, upload a resume, post a job, apply, review applicants, and schedule interviews.

The portal is built with plain HTML, CSS, and JavaScript, backed by Supabase for authentication, PostgreSQL storage, and private file storage. Access rules are enforced in the database with Row Level Security, not in the browser.
